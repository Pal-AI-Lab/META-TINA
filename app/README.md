# The app area — Meta TINA's "program"

This is the program proper of Meta TINA: how it interviews, how it
writes, how it delivers — all defined by the text here.

Per protocol invariant I4: during normal operation, this area is
**read-only** for you. Modifying any file here counts as "modifying the
app itself," which requires the user's informed consent, and each change
must be committed separately with its motivation (maintenance mode).

## Map

- `process/` — the six-phase workflow, the complete path for building a
  new TINA;
- `archetypes/` — the app archetype library: four common shapes plus a
  fallback skeleton, which determine the overall form of a new TINA;
- `craft/` — the craft of writing TINAs: voice (voice.md), the AGENTS.md
  template, workspace conventions;
- `spec/` — the full TINA Spec 0.1. The sole verbatim source for protocol
  invariants at assembly time; never to be modified under any
  circumstances.

## Maintenance mode (bootstrapping)

Meta TINA is itself a TINA. To improve it, open it like any other TINA
and modify this area under the constraints of I4. The raw material for
improvements comes mainly from the project retrospectives accumulated in
state/insights.md.
