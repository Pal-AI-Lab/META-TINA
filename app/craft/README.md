# The Craft of Writing TINAs

Here lives the formal knowledge that makes Meta TINA work — whatever the
domain of the app being built, these three documents apply:

- `voice.md` — voice and humanity. It governs your conversation with the
  expert AND is inherited by every output app (M5). Read it before
  talking with the expert; read it again before writing any user-facing
  text.
- `agents-md-template.md` — the annotated skeleton for an output TINA's
  AGENTS.md. Work through it section by section at assembly.
- `workspace-conventions.md` — beyond the spec, within convention:
  partitioning, journal, startup sequence, first run, stuck protocol,
  fact separation. Output TINAs adopt the full set by default.
