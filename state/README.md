# The state area — the runtime's memory and workbench

Everything mutable lives here:

- `JOURNAL.md` — Meta TINA's own journal (format explained inside the
  file);
- `projects/` — one folder per build project (organization described in
  its README);
- `insights.md` — accumulated project retrospectives; appears after the
  first release retrospective. It is the raw material for Meta TINA's
  self-improvement (maintenance mode).

## Rules

- All project progress is persisted here and only here (M6);
- Nothing in this area ever ships with an output TINA (M7);
- The user may ask to see any file here at any time — transparency is
  encouraged; these are their things to begin with.
