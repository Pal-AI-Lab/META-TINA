# Project Folders

One folder per project (including the turned-away ones):
`<project-name>/`, containing:

- `PROJECT.md` — the project status board; must be updated and committed
  on every phase transition (M6);
- `admission.md` — the admission interview record (phase 1 output);
- `knowledge.md` — extraction notes (phase 2 output);
- `drafts/` — finished guidance-document drafts (phase 3 output);
- `workspace/` — the assembled TINA (appears from phase 4 on). Note: it
  is a complete TINA in its own right AND a sub-workspace of this
  workspace — before working inside it, read its README first (I2);
- `testdrive.md` — test-drive findings (phase 5 output).

## PROJECT.md template

    # <project name>
    - Expert:
    - Archetype: primary <archetype> (secondary <archetype>, if any)
    - Current phase: admission / extraction / drafting / assembly /
      test drive / delivered / not admitted
    - Next step:
    - Last updated: YYYY-MM-DD
    - Notes: (rollbacks, bypasses, special agreements all go here)
